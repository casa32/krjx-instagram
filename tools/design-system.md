## 스토리 원칙 (story-writer FRAME)
- **1장(F):** 소리 없이도 이해되는 훅. 제품이 주는 결과·핵심을 2줄로.
- **한 장에 한 메시지(R):** 1장 첫인상, 2장 디자인·착용·특징, 3장 제품 정보+가격.
- **목표 하나(M):** 구매(프로필 링크). CTA는 3장에만, 하나만.
- **스티커(A):** 투표·질문·링크 스티커는 API로 못 붙임 → 필요하면 사용자가 앱에서 추가(현재 미사용).

## 피드 캡션 (caption-writer + instagram-seo + hashtag-strategy)
- 첫 줄 ✨제품명✨ 뒤 첫 문장(약 125자 안)에 검색 키워드(예: "순금 귀걸이", "24K 금목걸이", "종로 금거래소")를 자연스럽게.
- 본문: 상세페이지 설명 한두 줄 🤍 → ▫️ 스펙 → 구매 문의 → DM 안내 → 온라인 스토어 안내.
- **해시태그는 인스타 상한 5개:** 사용자 지정 지역 태그 5개(#종로금거래소 #종로귀금속 #종로3가 #종로금은방 #종로주얼리)만 쓰고, 제품 키워드는 해시태그 대신 캡션 본문에 넣는다.
